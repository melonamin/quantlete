# Gear

Track your equipment usage and maintenance.

## Gear List

The gear page (`/gear`) shows all your equipment from Strava:

- Bikes
- Shoes
- Other equipment

Each item displays:
- Name and brand/model
- Total distance
- Activity count
- Retirement status

## Gear Detail

Click a gear item to see detailed statistics:

### Usage Stats

- Total distance
- Total time
- Activity count
- First and last use
- Average distance per activity

### Activity Breakdown

- Activities by type
- Monthly usage trends
- Usage over time chart

### Components

For bikes, track individual components:
- Chain
- Cassette
- Tires
- Brake pads
- etc.

Each component shows:
- Install date
- Distance since install
- Recommended replacement distance
- Status (OK, Warning, Replace)

## Maintenance

Track maintenance activities for your gear:

### Logging Maintenance

1. Open gear detail page
2. Click "Add Maintenance"
3. Select component or general maintenance
4. Add description and date
5. Optionally reset component distance

### Maintenance Types

- **Service** - General servicing
- **Replacement** - Component replaced
- **Repair** - Fix specific issue
- **Cleaning** - Cleaning and lube

### Maintenance History

View all maintenance records:
- Date and type
- Description
- Component affected
- Distance at time of service

## Alerts

Get notified when maintenance is due:

- Components approaching replacement threshold
- Time-based service reminders
- Configure thresholds in settings

## Custom Gear

Add equipment not synced from Strava:

1. Click "Add Gear"
2. Enter name and type
3. Set initial distance (if transferring from old tracking)
4. Optionally add components
