# Activities

The Activities section lets you explore all your Strava activities.

## Activity List

The activity list (`/activities`) shows all imported activities with:

- Activity name and type
- Date and time
- Distance, duration, elevation
- Average pace/speed
- Heart rate and power (if available)

### Filtering

Filter activities by:
- **Activity type** - Run, Ride, Swim, etc.
- **Date range** - Custom date picker
- **Search** - Search by activity name

### Sorting

Sort by:
- Date (newest/oldest)
- Distance
- Duration
- Elevation gain

## Activity Detail

Click an activity to see its detail page (`/activities/{id}`):

### Overview Tab

- Full activity stats
- Splits table (per km/mile)
- Weather conditions (if available)
- Perceived exertion

### Map Tab

- Interactive route map
- Start/end markers
- Segment highlights

### Charts Tab

- Elevation profile
- Heart rate over time
- Power output (for cycling)
- Pace/speed variations
- Cadence

### Streams Data

If activity streams were imported:
- GPS coordinates
- Heart rate samples
- Power readings
- Cadence
- Temperature

## Calendar

The calendar view (`/calendar`) shows activities organized by date:

- Monthly calendar grid
- Activity type indicators
- Daily/weekly totals
- Click a day to see activities

## Heatmap

The heatmap (`/heatmap`) visualizes all your activities on a map:

- All GPS tracks overlaid
- Heat intensity shows frequency
- Zoom and pan controls
- Filter by activity type or date range

## Best Efforts

View your personal records (`/best-efforts`):

- Best times by distance (1K, 5K, 10K, etc.)
- Best power outputs (5s, 1min, 5min, 20min, 1hr)
- Trends over time
- Comparison to previous bests
